# DDJ-FLX4 LOW EQ: published MIDI path

Evidence: [Japanese vendor MIDI message list](../raw/rekordbox/flx4-midi-messages-j1.pdf#page=2), [FLX4 hardware diagram](../raw/rekordbox/flx4-hardware-diagram.pdf), [MIDI Learn guide](../raw/rekordbox/rekordbox-midi-learn-7.0.5.pdf#page=5), and [Rekordbox manual](../raw/rekordbox/rekordbox-manual-7.1.4.pdf#page=235). This is **documented behavior**, not a hardware test.

The vendor's mixer table lists two LOW EQ controls, one per deck, each with CC **15 (`0F`) MSB** and CC **47 (`2F`) LSB**. For MIDI channels 1 and 2, corresponding status bytes are `B0` and `B1`: messages are `B0 0F vv` / `B0 2F vv` and `B1 0F vv` / `B1 2F vv` respectively (`vv` is a 7-bit data byte). The PDF is Japanese and its text extraction does not preserve table columns well; confirm assignment against a hardware capture before relying on these bytes. Values span `00`–`7F` for each byte. For a conventional 14-bit pair, combined position is `128 * MSB + LSB` (0–16383); this is **controller position**, not EQ gain in decibels or filter cutoff frequency.

**Conceptual signal path:** knob movement → USB MIDI input → mapped Rekordbox LOW EQ function → software mixer processing in internal mixer mode → selected audio output. The [manual](../raw/rekordbox/rekordbox-manual-7.1.4.pdf#page=229) says Internal uses Rekordbox's mixer; [Mixer settings](../raw/rekordbox/rekordbox-manual-7.1.4.pdf#page=235) select EQ or ISOLATOR and EQ Type. The exact DSP transfer function, update smoothing, and dB mapping are **not specified** in these sources. No statement here establishes the FLX4 hardware's actual message stream on this machine or proves that another MIDI device can control Rekordbox concurrently.

**For program design:** store the mapping in versioned configuration. Decode hardware CC pairs with arrival timestamps; do not mistake a physical knob reading for the application's current EQ value. If issuing values via a virtual MIDI port, first test USB/virtual-device visibility, mapping, and whether hardware can override the command.
